`Select` is a form component that allows users to choose one or multiple values from a predefined list of options.

It supports single and multiple selection modes, searchable options, inline option creation, validation states, and customizable visual properties such as variant, color, size, and border radius.

> **Note:** All examples below are interactive. Use Storybook Controls to modify available properties and test different component behaviors.

---

## Variant

`Select` supports the same visual variants as other form components. Each variant provides a different level of emphasis and can be selected based on the desired appearance within the form layout.

For consistent design, use the same variant style across related form components.

<Canvas of={SelectStories.Variant} />

---

## Color

The component supports multiple color options to match different interface states and design requirements.

Each color can be combined with supported variants to create consistent visual feedback across your application.

---

## Size

`Select` provides different size options for various layout requirements.

Smaller sizes are suitable for compact interfaces, while larger sizes improve readability and accessibility in prominent form areas.

<Canvas of={SelectStories.Size} />

## Border Radius

The border radius controls the corner appearance of the component.

Use consistent radius values across form components to maintain visual harmony throughout the interface.

<Canvas of={SelectStories.Radius} />

## Disabled

The disabled state prevents user interaction and indicates that the field is temporarily unavailable.

This state is commonly used for unavailable fields, restricted actions, or values that cannot currently be modified.

<Canvas of={SelectStories.Disabled} />

---

## Read Only

The read-only state allows users to view the current value while preventing modifications.

It is useful for displaying fixed information while keeping the component visually consistent with editable fields.

<Canvas of={SelectStories.ReadOnly} />

---

## Validation

Validation provides visual feedback for invalid or incomplete user input.

The validation message visibility can be controlled through configuration, allowing forms to either display the message directly or only apply the validation state styling.

<Canvas of={SelectStories.Validation} />

## Clear Button

The clear functionality allows users to remove the current selection and reset the field value.

This behavior improves usability when users need to quickly remove an existing selection.

<Canvas of={SelectStories.ClearButton} />

## With Search

Search functionality enables users to filter available options by entering text.

It is recommended for select fields containing a large number of options where manually browsing the list would be inefficient.

## With Create

The create functionality allows users to add a new option when the required value does not already exist in the available options.

This is useful for dynamic data scenarios where users can introduce new values.

Multiple selection allows users to select more than one option from the available list.
